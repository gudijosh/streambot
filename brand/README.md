# Artes de la marca

Los archivos de esta carpeta se cargan solos en StreamBot. Cada hueco usa un nombre fijo:

| Archivo | Uso |
|---|---|
| `logo.png` | Marca de agua del directo y de los clips |
| `avatar.png` | Avatar del personaje junto a los subtítulos |
| `frame.png` | Marco a pantalla completa (1920 × 1080, transparente) |
| `starting.png` o `.mp4` | Fondo de «Empezamos pronto» |
| `brb.png` o `.mp4` | Fondo de «Vuelvo enseguida» |
| `ending.png` o `.mp4` | Fondo de «Fin del directo» |
| `alert.png` | Imagen de las alertas |
| `alertSound.mp3` | Sonido de las alertas |

Imágenes: png, jpg, webp o gif. Vídeos: mp4 o webm. Sonidos: mp3, wav, ogg o m4a.

Lo que subas desde la pestaña Marca del panel tiene prioridad sobre lo que haya aquí.
